# EPIC-01 — Project Initialization & Infrastructure

## Goal

Initialize Next.js project with App Router, Tailwind, TypeScript, and base infrastructure following FSD and best practices.

## Tasks

1. Create Next.js project with App Router
2. Configure Tailwind CSS (dark/light themes)
3. Setup ESLint + Prettier
4. Configure absolute imports
5. Prepare base layout (Header/Footer placeholders)
6. Setup environment variables

## Files & Folders to Create

- src/app/layout.tsx
- src/app/page.tsx
- src/shared/config/env.ts
- src/shared/ui/
- tailwind.config.ts
- postcss.config.js

## Acceptance Criteria

- App starts without errors
- Tailwind styles apply
- Dark/Light theme switch works
- Build passes successfully
